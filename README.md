
# Git Jedi Training 🪐✨

Проект создан в процессе обучения эффективной работе с Git и GitHub под руководством цифрового мастера Йоды.

## 📚 Что внутри?
- Файлы с знаниями о вселенной Звёздных Войн
- Идеальная история коммитов (семантические сообщения, линейная структура)
- Примеры работы с ветками, слияниями, конфликтами

## 🛠️ Технологии
- Git (все основные команды и продвинутые техники)
- GitHub (удалённые репозитории)

## 🎯 Цель проекта
Продемонстрировать мастерское владение Git через тематику Звёздных Войн.
